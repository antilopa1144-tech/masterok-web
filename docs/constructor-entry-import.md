# Открытие файла проекта со стартовой страницы

Дата проверки: 7 октября 2026 года.

## Изменение

На `/konstruktor/` и `/konstruktor/vannaya/` появилась кнопка «Открыть файл проекта». Пользователь выбирает резервную копию `.masterok.json` и попадает сразу в редактор. Создавать промежуточный проект больше не нужно.

Импорт использует существующую проверку формата версий 1–5 и создаёт новый идентификатор. Помещения, материалы, цены и варианты отделки сохраняются; существующие проекты не перезаписываются. Переход выполняется только после успешной записи копии в IndexedDB. Если пользователь покинул страницу во время чтения, запись ещё не начавшегося импорта отменяется.

Файлы больше 4 МБ отклоняются до чтения. Ошибки формата, чтения и сохранения остаются рядом с кнопкой; фокус переходит к сообщению, повторный выбор доступен. Обработчик блокирует повторный запуск во время импорта. Обработка файлов загружается динамически после выбора файла.

Редактор и стартовая страница используют общий `readWorkspaceFile`. Расчётные формулы, настройки материалов и округления не менялись. FAQ обеих страниц теперь объясняет фактический путь переноса проекта между устройствами.

- `src/lib/constructor/import.ts`, `workspace.ts` — чтение, проверка и сохранение отдельной копии.

## Границы проверки

Проверка мобильного интерфейса выполнена в браузере с заданной шириной, не на физическом телефоне. Недоступность диска и ошибка IndexedDB проверены тестами с подменой сбоя. Для успешного браузерного импорта использован проверочный файл, созданный штатным сериализатором: инструмент не получил событие скачивания после экспорта через интерфейс, поэтому полный цикл скачивания файла из браузера отдельно не подтверждён.

В dev-среде сохраняется ранее наблюдавшееся предупреждение гидратации nonce в корневом layout; layout и middleware этой задачей не менялись. Публикация production и рост поискового трафика этой проверкой не подтверждаются.
