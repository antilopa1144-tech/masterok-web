# Обновление Tailwind CSS до 4.3.3

Обновляем Tailwind CSS и `@tailwindcss/postcss` вместе: с 4.2.0 до точной версии 4.3.3. Интеграция через PostCSS сохраняется. Next.js, React, TypeScript и Three.js в этом этапе не меняются.

Цель этапа — обновить CSS-компилятор и проверить совместимость существующего интерфейса. Само обновление не является редизайном и не обещает улучшение качества 3D.

Вместе с Tailwind обновляются его собственные пакеты node/oxide, CSS-оптимизатор Lightning CSS и зависимости разрешения модулей. Версии остальных прямых зависимостей сохраняются.

Проверяем production-сборку, тесты, lint и TypeScript; сравниваем главную, страницы конструктора и калькулятор на компьютере и мобильных ширинах в светлой и тёмной темах. В редакторе проверяем сохранение, сравнение вариантов, отмену, перезагрузку, импорт и блокировку неверного ввода.

Известная непостоянная ошибка React #418 остаётся отдельным вопросом. Повторные диагностические входы 13 октября её не воспроизвели. Отчёт React о гонке потоковой загрузки — гипотеза, а не подтверждённая причина на нашем сайте; подавление ошибки или изменение React runtime в обновление Tailwind не включаем.

Официальное описание версии: https://tailwindcss.com/blog/tailwindcss-v4-3

Артефакты проверок: `output/constructor/tailwind-upgrade-2026-10-13/`.

Локальная проверка: 4112 тестов в 305 файлах, lint, TypeScript и production-сборка прошли. На 12 сочетаниях четырёх страниц и экранов 1440/390/320 px сравнение видимых заголовков, ссылок и кнопок не выявило различий геометрии свыше 0,5 px или изменений проверенных цветов и шрифтов. Импорт файла проекта, сравнение, применение, отмена, повтор, перезагрузка и неверный ввод проверены в браузере. Проверки телефона выполнены в эмуляции, не на физических устройствах.
