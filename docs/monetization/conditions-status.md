# Статус условий покупки и внешних программ

Актуально на 22.09.2026. Страница `/usloviya-pokupki/` динамическая и `noindex`: она читает только публичную часть настроек. Цены пакета и PRO — настраиваемые гипотезы до реального договора; бесплатные расчёты, экспорты и локальные проекты сохраняются бесплатными. Пустые реквизиты означают тестовый, юридически неготовый контур.

Документ фиксирует статус, а не даёт юридическое заключение. До публичного запуска пройти [runbook](./runbook.md), согласовать оферту, возвраты, НПД-чеки, ПД и каждую рекламу/партнёрскую интеграцию.

## Ограничения принятого решения

Для самозанятого Robokassa — первый кандидат, поскольку сервис [публично поддерживает НПД](https://robokassa.com/solutions/business/samozanyatye/). В доступном кабинете владельца 23.09.2026 создан отдельный магазин `getmasterok` для getmasterok.ru со статусом «Новый». Технические параметры и договор ещё не готовы, активация не запрошена. Используем стандартную подписанную оплату, а не выдуманный API.

Проверка 23.09.2026 после уточнения владельца: его банк — Т‑Банк; он **самозанятый-физлицо без ИП**. [Т‑Банк прямо указывает](https://www.tbank.ru/business/help/business-payments/internet-acquiring/how-work/working-conditions/), что интернет-эквайринг доступен самозанятому со статусом ИП, но не самозанятому-физлицу. [Личные запросы денег](https://www.tbank.ru/bank/help/general/self-employed/work/invoices/) допускают получение перевода, однако чек формируется вручную и публичного контракта автоматического подтверждения заказов для этого пути не установлено. Поэтому такой перевод нельзя использовать для мгновенного серверного открытия платной сметы. [Прямой СБП](https://cbr.ru/press/event/?id=12274) с предельной ставкой до 0,4% для НПД следует оценивать только у банка, который реально подключит физлицо и даст автоматическое подтверждение заказа; ставка СБП через агрегатор может быть выше. Выбор Robokassa остаётся предварительным до проверки магазина, тестового платежа и чеков. Регистрация ИП только ради экономии нескольких рублей комиссии на продаже сметы сейчас не обоснована.

Яндекс допускает самозанятых, но открытая программа ориентирована прежде всего на контентные площадки; требуется письменное подтверждение, что разрешён именно getmasterok.ru и его блоки закупки. Комиссии зависят от товара/договора, не зашиты в доходную модель. Товарная ссылка и API статистики не равны доступу к актуальному каталогу, ценам и остаткам. Для Лемана ПРО открытые ставки не подтверждают статус НПД, длительность атрибуции, доступ к фиду, разрешённый канал и выплаты конкретно этому владельцу. Все предложения пока выключены.

Ограничения НПД для агентских/комиссионных отношений нужно проверить по фактическому договору; рекламное размещение и агентская продажа — разные отношения. [ФНС об НПД](https://npd.nalog.ru/). Автоматически объявлять любую партнёрскую программу разрешённой или запрещённой нельзя.

Для персональных данных учесть [изменения 156-ФЗ](https://publication.pravo.gov.ru/document/0001202506240021) об отдельном оформлении согласия и [изменения 23-ФЗ](https://publication.pravo.gov.ru/document/0001202502280034) о локализации; определить реальные цели/основания и обработчиков. Для рекламы отдельно подтвердить маркировку, ORD/ЕРИР и применимость отчислений по роли/договору. Ни заполнение ERID, ни галочка `legalApproved` сами по себе не заменяют исполнения требований.
