# Сначала разовая покупка — решение 23.09.2026

По указанию владельца первым проверяем один продукт: «Смета проекта в PDF и XLSX», 249 ₽ за конкретный проект. Цена — гипотеза, не доказанная готовность аудитории платить.

## Что покупает человек

Оформленный комплект по одному объекту: смета материалов и работ, закупочный список, редактируемый XLSX, PDF для передачи заказчику/исполнителю, фактически сохранённые раскладки. Несколько комнат и расчётов могут входить в один проект. Исправления и повторное скачивание этого проекта не требуют новой оплаты. Это не подписка. Бесплатные калькуляторы, текущие проекты и бесплатные выгрузки сохраняются.

До оплаты показываем состав конкретного проекта, предварительный вид документа, известный итог и число строк без цены. Не обещаем актуальные магазинные цены, замеры или инженерную проверку. Продавать только визуальное оформление слабее, чем экономию времени на подготовке целого документа.

## Варианты следующего продукта

| Вариант | Решение |
| --- | --- |
| Оплата каждого файла/повторной выгрузки | Не использовать: исправления становятся платным препятствием. |
| Один проект за 249 ₽ | Первый запуск. Один понятный результат без автосписаний. |
| Предоплаченные несколько проектов | Возможный следующий шаг для нерегулярно работающих мастеров; сначала измерить повторные покупки. |
| Доступ на 30–90 дней для своего ремонта | Рассматривать только при появлении востребованного ведения бюджета и закупок во времени. Не называть подпиской простую выгрузку сметы. |
| PRO для регулярно работающих мастеров | Наиболее обоснованный будущий месячный продукт: свои расценки, повторное применение шаблонов, версии и сравнение смет, документы подрядчика. 399 ₽/месяц — только стартовая гипотеза. |
| Безлимитный AI как основа тарифа | Не запускать: переменная себестоимость и недостаточно подтверждённая ценность. Дополнительные лимиты считать отдельно. |

Подписка должна оплачивать повторяющуюся работу. Для владельца квартиры с эпизодическим ремонтом разовая покупка лучше соответствует задаче. При аудитории 6–7 тысяч посетителей (данные владельца, не свежая аналитика) не дробить первый запуск на множество тарифов и экспериментов.

## Условия и состояние подключения

В [требованиях Robokassa](https://robokassa.com/how-works/) для самозанятого указаны полные ФИО и ИНН; сведения можно собрать в доступной до оплаты оферте. Публичный блок «Статус реквизитов и запуска» заменён на «Продавец и поддержка». Внутренние флаги убраны. Паспорт и домашний адрес не нужны в этом блоке. Это проверка требований провайдера, не заключение о полной юридической готовности.

[Remplanner PRO](https://remplanner.ru/planner/pro/) объединяет смету с чертежами и PDF-документацией: ориентир для полезности комплекта, не основание копировать цену или обещать равноценность продукта. Официальные страницы проверены 23.09.2026.

В локальной админке продажа PRO выключена; уже выданные тестовые права сохранены. Общие production-флаги и договоры не менялись. Платёж остаётся локальной симуляцией до настройки тестовых ключей и HTTPS-уведомлений Robokassa, проверки чеков НПД, условий продажи и активации магазина. Реальные списания и публикация требуют отдельного согласования.

## Приёмка и метрики

Различать этапы: полезно заполненный проект → просмотр образца → создание заказа → подтверждённая оплата → успешный документ → повторная выгрузка. Отдельно считать возвраты, обращения в поддержку и повторные проекты через 30/60 дней. Первые продажи использовать для интервью и выявления препятствий, не для обещаний статистически значимого роста.

Кнопка проверки оплаты читает серверное состояние заказа; сама не подтверждает платёж и не делает прямого запроса в Robokassa. При ожидании показывает понятный ответ, после подтверждённой оплаты уступает место скачиванию документов.
