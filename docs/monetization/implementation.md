# Монетизация: принятый объём

План согласован владельцем 22.09.2026. Владелец — самозанятый; договоров партнёрских программ пока нет, возможный кабинет Robokassa нужно подтвердить. Публикация, реальные списания и договоры не разрешены в этой реализации.

Покупатель платит за определённое действие: **оформить смету одного проекта в PDF для заказчика и XLSX для правок** (гипотеза 249 ₽), либо **повторять работу со сметами заказчиков** — шаблоны, версии, сравнение и документы для нескольких проектов без разовых покупок (PRO, гипотеза 399 ₽/месяц). Внутренний идентификатор первого продукта по-прежнему `project_pack`, но покупателю показывается «Смета проекта в PDF и XLSX» — в предложении, заказе, кабинете и чеке. Тарифы не являются подтверждённым спросом. Данные исполнителя входят и в разовую смету: их нельзя вырезать из оплаченного документа для заказчика только ради различия тарифов.

Состав и цена показываются рядом с черновиком сметы до входа в кабинет. В карточке названы PDF, XLSX, число материалов/работ/схем и незаполненные цены. Закупочный список остаётся бесплатным; в оплаченные файлы он только включён. Покупка не предлагается, пока ни у одной материальной позиции или работы нет введённой цены; это проверяется и интерфейсом, и сервером. Оплата становится доступной только после входа и серверного сохранения проекта. Экран заказа отдельно показывает текущий известный итог сметы и стоимость оформления, чтобы не путать их, и повторяет статус покупки и недостающие цены. Тестовый режим обозначен отдельно.

## Бесплатная граница

Сохраняются все калькуляторы, существующие PDF/CSV/печать, локальные проекты, цены и отметки закупки, текущие возможности Михалыча. Редактирование объединённой корзины и подбор материалов также бесплатны. Отдельная покупка Project Pack не зависит от подписки. Отмена PRO не удаляет проекты и ранее сформированные документы.

## Архитектура

- Существующее IndexedDB-хранилище остаётся источником локальных проектов.
- Платёжный и серверный проектный контур использует PostgreSQL и транзакции. Для локальной проверки без Docker применяется PGlite с тем же SQL; для sandbox/live требуется отдельный PostgreSQL.
- Вход по одноразовому коду, серверные сессии в HttpOnly-cookie. Локальный код показывается исключительно в режиме `local`; в sandbox/live требуется SMTP.
- Бесплатное ядро и формулы калькуляторов не зависят от доступности магазина, оплаты или серверной БД.
- Режимы `off`, `local`, `sandbox`, `live` разделены. По умолчанию `off`. Симуляция не является песочницей Robokassa.
- Права проверяются сервером на каждый проект, экспорт, шаблон и историю. Ключи, состав проектов и персональные данные не передаются в продуктовую аналитику.

## Пилот закупки

Свежий рейтинг калькуляторов пока не получен. 10 кандидатов выбраны как **продуктовая гипотеза**, а не по измеренной конверсии: штукатурка, шпаклёвка, грунтовка, краска, плитка, плиточный клей, затирка, ламинат, наливной пол, гидроизоляция. Общие 6–7 тысяч уникальных посетителей в месяц сообщены владельцем, не проверены этим запуском.

Объединять разрешено только доказанно совместимые материалы, после сложения точной потребности с уже учтённым запасом. При неизвестной спецификации строки остаются раздельными. Название и единица сами по себе не доказывают совместимость. Не извлекаем размеры упаковки из рекламного текста.

## Приёмка

Расчёты → несколько помещений → корзина → редакция проекта → предварительный просмотр документа → вход → тестовая оплата → доступ → PDF/XLSX → повторный вход/скачивание → отмена PRO/возврат. Отдельно проверяются подмена суммы, чужой проект, повторное/запоздавшее уведомление, потерянный callback, истечение доступа, пустые цены, мобильная ширина и документы с кириллицей.

## Оценка после включения

Результат → подбор → корзина → исходящий переход. Отдельно: подтверждённые заказы партнёра, начисление, возврат, фактическая выплата. Для собственных продуктов — начало оплаты, оплаченный заказ, использование документа, возврат, повторная работа и продление PRO. Экономика включает комиссию оплаты, налоги, применимые рекламные отчисления, ИИ, инфраструктуру и поддержку. Срок наблюдения не заменяет достаточное число событий. Бесплатное завершение расчётов и скорость — защитные метрики.
