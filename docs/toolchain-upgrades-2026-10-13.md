# Обновление инструментов — 13 октября 2026

## TypeScript 7

- `@typescript/native` — точный npm alias на `typescript@7.0.2`.
- `typescript` — официальный пакет совместимости `@typescript/typescript6@6.0.2`; зафиксированный lockfile разрешает его API в TypeScript 6.0.3.
- `npm run typecheck` явно запускает нативный компилятор 7.0.2. В CI существующий шаг Check TypeScript использует эту команду.
- `npm run typecheck:compat` запускает `tsc6`. ESLint и встроенная проверка Next.js продолжают использовать совместимый API. Проверки сборки не отключены.
- Изменений формул, интерфейса и runtime-поведения сайта нет.

Три последовательных прогона одного чистого снимка проекта на Windows / Node 24.11.0, `--noEmit --incremental false`, порядок компиляторов чередовался:

| Компилятор | Прогоны, с | Медиана, с |
| --- | --- | ---: |
| Совместимый API / tsc6 (6.0.3) | 12.051; 12.291; 12.195 | 12.195 |
| Нативный tsc (7.0.2) | 1.448; 1.060; 1.274 | 1.274 |

Ускорение отдельной проверки типов — около 9,6 раза. Это не замер полной сборки Next.js или скорости сайта. Каждый прогон завершился без ошибок.

Проверки этапа: ESLint без предупреждений, 4 130 тестов в 314 файлах, production build Next.js. Артефакты: `output/typescript7-2026-10-13/`.

## Vitest 5

- Vitest 3.2.6 → 5.0.4, Vite остаётся 7.3.5. Node.js 24 удовлетворяет требованиям новой версии.
- В двух тестах форм создания помещения и проёма уточнён тип mock-функции отмены: `() => void`. Утверждения и сценарии тестов не ослаблены.
- Первый полный прогон новой версии: те же 4 130 тестов в 314 файлах проходят. Новый дефолт очистки истории mock-вызовов между тестами совместим с существующими сценариями.
- Руководство миграции: https://vitest.dev/guide/migration/

## ESLint 10: отложен по совместимости

На дату проверки npm latest: ESLint 10.12.0, но актуальные `eslint-plugin-react@7.37.5`, `eslint-plugin-jsx-a11y@6.10.2` и `eslint-plugin-import@2.32.0` объявляют поддержку только до ESLint 9. Эти плагины входят в конфигурацию Next.js. Оставлен ESLint 9.39.5; принудительное разрешение несовместимых peerDependencies не применялось.

Источник схемы совместной установки: https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/#running-side-by-side-with-typescript-6-0
