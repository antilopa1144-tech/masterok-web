# Возврат к проекту и резервная копия из ведомости

На главной посетитель с сохранённым проектом видит «Продолжить проект»,
название, количество помещений и дату изменения. «Мои проекты» открывает
существующий список с поиском. Для нового посетителя остаётся обычный вход
в конструктор и выбор примеров. Наличие проекта определяется в браузере;
содержимое проекта не уходит на сервер главной страницы.

Главная и посадочные используют общий hook чтения активного проекта.
Он обновляет данные при pageshow, возврате фокуса и видимости вкладки;
старые ответы и ответы после ухода со страницы игнорируются. Ошибка
хранилища возвращает обычное состояние без ложного сохранённого проекта.
Список проектов теперь сам задаёт CSS-переменные светлой и тёмной темы.

В ведомости добавлен блок «Продолжить на другом устройстве» с кнопкой
скачивания .masterok.json и пояснением импорта через страницу конструктора.
Кнопка использует существующий экспорт и его ограничения ввода/валидации.
Формат файла, импорт, расчёты, запас, упаковки и локальное хранилище не менялись.
Это перенос через файл; автоматической синхронизации между устройствами нет.

Входы в аналитику различаются по home_resume, home_saved_project
и landing_saved_project; scenario=continue. Экспорт использует существующее
constructor_export format=project. Названия, даты, ID и количества не отправляются.

Проверки в чистой копии репозитория:

- 4054 теста, lint, TypeScript, production-сборка с каталогом Ghost.
- Первый вход, сохранение, возвращение на главную и повторное открытие того же ID.
- История браузера: после нового примера кнопка ведёт в последний проект,
  а выбор старого проекта в списке сохраняет его идентичность.
- Список, пустой поиск, очистка, возврат фокуса после закрытия диалога.
- 1440, 390 и 320 px, светлая/тёмная темы, длинное название; нет переполнений.
- Скачивание из ведомости, открытие файла в чистом браузерном контексте:
  3750 × 4200 мм, светлый ламинат, 15,75 м², 9 упаковок, сохранённый вариант.
- Тест адаптера аналитики: возврат с главной, выбор в списке, экспорт проекта.

SSR-заголовок и ссылки главной сохраняются. SEO-маршруты, метаданные и sitemap
не менялись. Проверки браузерных контекстов не заменяют проверку физического
телефона и не подтверждают получение событий в кабинетах аналитики.
