# Материалы в карточках сравнения и инструкция для ванной

Раньше каждая карточка показывала четыре строки: ламинат, его раскрой, плитку и её раскладку. Поэтому в ванной с плиточным полом появлялись нулевые строки ламината, а в комнате без плитки — строки с прочерками. Теперь видны только назначенные группы материалов. В проекте с обоими покрытиями остаются все четыре строки, даже если в превью выбрана только ванная. Признак назначения берётся из существующей сводки всего проекта, а не из выбранной комнаты или нулевого количества упаковок.

Расчёт, упаковки, запас, потери, цены и формат файла не меняются. Уточнение касается представления. Снимки вариантов рассчитываются и показываются независимо, как раньше.

Страница `/konstruktor/vannaya/` объясняет сохранение двух вариантов плитки, просмотр планов, расхода и материалов стен, условия сравнения стоимости и восстановление всего проекта. Добавлены раздел, ссылка в навигации и видимый вопрос. Развёртки стен остаются в редакторе; окно сравнения показывает план пола. Обновлены описание ванной в `llms.txt` и дата содержательного изменения в sitemap.

Регрессионные проверки фиксируют три случая: проект только с плиткой, только с ламинатом и с обоими покрытиями при просмотре ванной. До изменения первые два случая показывали лишние строки. Браузерная проверка включает мобильные ширины, сохранение/применение/отмену, импорт файла со смешанным проектом и доступность инструкции без JavaScript.
