## Какие запросы ведут на URL

В Google прочитаны видимые строки **Queries** после exact page filter. Для Яндекса дополнительно вызван read-only `query-analytics/list` на VPS, фильтр `URL TEXT_MATCH`, текстовый индикатор `QUERY`, поиск `WEB_LOCATION`, все устройства. API вернул 07.09–20.09; `count = returned` для всех четырёх проверенных URL ниже. Это **14 дней**, поэтому отдельные запросы Яндекса не сравниваются по объёму с 28-дневной таблицей. Остальные входы не забыты: рейки уже получают 254 клика Яндекса при 9,65% CTR, но формулировка Google «как рассчитать количество реек на стену» пока 0/32 и не является доказательством дефекта. Статья о стяжке собирает 359 кликов Яндекса; её сезонный расчётный интент уже отделён в прогнозе от огромного общего спроса на «тёплый пол». Главная даёт главным образом общие/брендовые запросы. Тротуарная раскладка имеет 106 кликов Яндекса при хорошем CTR, но сейчас не опережает внутренние работы осенью-зимой. По этим четырём URL не меняем мета на основании одной группы строк.

## Очередь после карты

1. **Линейный раскрой, владелец URL — существующий инструмент.** Проверить реальный default-сценарий, результаты/экспорт и выпустить один содержательный пример для трубы или профиля: список деталей, хлыст, пропил, карты, целые заготовки к покупке и честные ограничения. Статью связать с инструментом и релевантными рейками; без новой конкурирующей страницы «калькулятора раскроя трубы». База измерения: Google 34/741, Яндекс 111/3 333, Метрика 263 входа в названных окнах. Через 4–8 недель после публикации смотреть запросы URL, входы материала и действия в инструменте, а не обещать прирост сейчас.
2. **Раскладка листов, владелец URL — существующий инструмент.** Разбор ОСБ/ГКЛ на конкретной прямоугольной поверхности и схема закупки с целыми листами; сначала визуально и математически проверить пример. Отделить эту задачу от раскроя неодинаковых мебельных деталей и не заявлять универсальный 2D-оптимизатор. База: Google 10/146, Яндекс 240/2 115, Метрика 334. Перед публикацией проверить, нет ли уже идентичной статьи в Ghost; один содержательный материал лучше двух дубликатов.

По плитке отдельная диагностическая проверка нужна только если следующее полное окно подтвердит снижение **целевых** кликов при сравнимых запросах/позициях. По ламинату развитие через полезный результат и передачу, не через замену работающей семантики. Список десяти URL — приоритетная выборка по входам, не полный аудит индекса и не прогноз трафика.
