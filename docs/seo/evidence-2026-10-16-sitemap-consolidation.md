## Старые sitemap

Пять отдельных отправок `/sitemap/0.xml`–`4.xml` сохраняли Couldn't fetch. Повторная отправка `/sitemap/0.xml` 16 октября принята формой, но снова получила Couldn't fetch / Sitemap could not be read. Точную сетевую причину интерфейс не сообщает. Не объявляем причиной Timeweb, анти-DDoS или XML без соответствующего доказательства.

Live URL Inspection в 06:45:03 UTC для `/sitemap/0.xml`: Google Inspection Tool smartphone, Crawl allowed=Yes, Page fetch=Successful. В SOURCE виден настоящий XML urlset с адресами сайта. Это исключает утверждение, что старый адрес постоянно недоступен любому роботу Google; расхождение с Sitemap report остаётся. Общая карта выбрана как подтверждённо работающий путь, а не как доказанное исправление сетевого слоя.

Плоская `/sitemap-pages.xml` уже прочитана Google: 159 URL, errors=0, warnings=0. Основной индекс `/sitemap.xml` теперь направляет на эту общую карту вместо пяти старых частей. Сами части сохраняют прежние адреса и содержимое для совместимости; состав URL, даты страниц и правила robots не меняются. Новых страниц в этом выпуске нет.

После публикации требуется проверить равенство наборов URL общей карты и старых частей, повторно отправить индекс и проверить именно чтение Google. Удаление устаревших отдельных отправок из отчёта допустимо только после проверки рабочей цепочки; оно не исправляет транспортную доступность старого адреса и не удаляет страницы из индекса.

Источники: [управление sitemap в Search Console](https://support.google.com/webmasters/answer/7451001?hl=en), [sitemap index](https://developers.google.com/search/docs/crawling-indexing/sitemaps/large-sitemaps).

## Мобильный сценарий

Случайное нажатие корзины у двери или окна больше не удаляет проём сразу. Появляется подтверждение с названием, отмена возвращает фокус к исходной кнопке. Подтверждённое удаление использует прежнюю историю проекта и восстанавливается кнопкой «Отменить действие». Расчётные формулы, запас, фасовка и значения по умолчанию не менялись.

Локальные исходные данные, снимки Google, результаты тестов, SHA и итог публикации: `output/sitemap-crawl-mobile-2026-10-16/`.
