# Ламинат: запросы и URL Яндекса, 10 сентября 2026

## Решение

Сохранить отдельные назначения калькулятора количества и визуальной раскладки. Нового URL «калькулятор ламината со схемой» не создавать. Ведущие запросы схемы связаны с инструментом, общий запрос калькулятора — с калькулятором количества. Статья о смещении также получает поисковые переходы. Это не доказательство отсутствия любой каннибализации.

## Что проверено

Получены два независимых отчёта [query-analytics/list Яндекс Вебмастера](https://yandex.ru/dev/webmaster/doc/ru/reference/host-query-analytics): QUERY с подстрокой «ламинат» и URL с подстрокой «laminat». Стандартная органическая выдача WEB_LOCATION, все устройства и регионы. Реальный период ответа: 25 августа — 7 сентября 2026. Пагинация завершена, дубликатов ключей нет, типы строк и фильтры проверены. Дневные суммы кликов и показов независимо пересчитаны PowerShell и Python.

Кабинетные показатели и полная выгрузка остаются в gitignored `.local-analytics/`: `yandex-laminate-query-2026-09-10.json`, `yandex-laminate-summary-2026-09-10.json`, `yandex-laminate-analysis.ipynb`. Notebook-код выполнен последовательно через Python с assertions; nbformat/nbclient отсутствуют, запуск через Jupyter не проверен. Секреты не выгружались. Установленные мониторинги и их расписания не изменялись.

Ограничение отчётного инструмента: portable HTML builder отклонил API/Python provenance, требуя SQL для графика. Готовый HTML не создан; подменять происхождение данных вымышленным SQL нельзя. Проверенный результат сохранён в этой карте решений и приватном notebook. Это ограничение оформления, не доступа к статистике.

Popular complementary URL — наиболее частая страница, а не полная матрица запрос × URL. Суммы QUERY и URL не складывать; они имеют разные фильтры и зерно. CTR считается отношением сумм, не средним дневных CTR. Позиция и причинный эффект правок этим отчётом не оценивались. Срезы GSC/Wordstat с другими периодами не объединялись с Яндексом.
