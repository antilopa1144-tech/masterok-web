# Общий калькулятор кровли: диагностический снимок 2026-08-02

URL: `https://getmasterok.ru/kalkulyatory/krovlya/krovlya/`

## Факты

- Google Search Console, 2026-05-03 — 2026-08-01: 71 показ, 3 клика,
  CTR 4,2%, средняя позиция 15,1.
- Среди запросов Google к общему URL есть интенты мягкой и наплавляемой
  кровли, хотя для гибкой черепицы на сайте уже существует более полный
  специализированный калькулятор.
- Яндекс Вебмастер, выгрузка за 30 дней: запрос
  `расчет материалов для кровли онлайн калькулятор` получил 6 показов,
  2 клика и среднюю позицию 7,5.
- В ветке мягкой кровли общий калькулятор повторял старую ошибочную конвертацию
  гвоздей из штук в килограммы и показывал около 20 кг к покупке для крыши
  площадью 80 м² в плане при уклоне 30°.
- Специализированный калькулятор мягкой кровли уже использует расход из
  инструкции ТЕХНОНИКОЛЬ SHINGLAS: 0,10 кг/м² при уклоне до 45° и
  0,15 кг/м² при большем уклоне.

## Решение

- Сохранить общий URL для сравнения металлочерепицы, профнастила, ондулина и
  шифера; не расширять его SEO-сниппет под мягкую кровлю.
- Поставить явную внутреннюю ссылку на специализированный калькулятор мягкой
  кровли, где учтены ендовы, карнизы и подкладочный ковёр.
- Синхронизировать расход гвоздей общего калькулятора с canonical-правилом:
  точная масса, запас 5% и покупка коробок по 5 кг.
- Не показывать предупреждение о минимальном уклоне металлочерепицы для других
  типов покрытия.

## Гипотеза

Разведение интентов уменьшит слабую каннибализацию общей и специализированной
страниц. Исправленный расчёт убирает заметную ошибку результата и риск потери
доверия. Основной рост общего URL требует продвижения с позиции около 15;
одного изменения сниппета для этого недостаточно.
