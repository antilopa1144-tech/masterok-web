### `noindex`

62 tag-архива блога закрыты намеренно: отдельного действия по массовому снятию
`noindex` нет. URL `/instrumenty/kalkulyator/` также закрыт намеренно и уже
исключён из sitemap.

Старые URL калькуляторов:

- `/kalkulyatory/otdelka/putty/` — 301 уже был настроен;
- `/kalkulyatory/otdelka/wallpaper/` — нужен 301 на `/oboi/`;
- `/kalkulyatory/otdelka/primer/` — нужен 301 на `/gruntovka/`;
- `/kalkulyatory/fundament/gidroizolyaciya/` — нужен 301 на актуальный
  калькулятор гидроизоляции.

### Просканировано, но не проиндексировано

Технические URL — шесть sitemap XML и RSS — не являются посадочными страницами.
Старый кириллический tag URL уже покрывается транслитерационным 301.

Остаются 16 реальных HTML-посадочных:

- 11 калькуляторов: реечный потолок, гипсокартон, радиаторы, стяжка,
  утепление фасада, краска, плитный фундамент, облицовочный кирпич,
  тёплый пол, утепление потолка, забор;
- 5 статей: расчёт ламината, расход краски, электрика, расчёт фундамента,
  выбор стяжки.

Общего технического запрета для этой группы не найдено. Часть страниц Google
обходил до последних улучшений сайта. Следующее действие — не массовая смена
metadata, а приоритизация по показам и интенту, усиление внутренних ссылок и
повторная проверка после нового обхода.

## Решения спринта

1. Удалить из GSC ошибочно отправленную `/stitemap.xml`; оставить только
   успешную `/sitemap.xml`.
2. Добавить постоянные редиректы для трёх подтверждённых старых URL.
3. Не перенаправлять мусорные `/$` и `/&` на главную.
4. Не снимать `noindex` с tag-архивов массово.
5. Не менять canonical параметрических инструментов: сохранённый обход
   24 июля не видел canonical, но live-тест GSC 28 июля распознал
   `https://getmasterok.ru/instrumenty/kalendar-remonta/` как
   user-declared canonical для параметрического URL.
6. Следующий контентный спринт начать с ламината, затем отмостки/фундамента.

## Следующая проверка

- После production-деплоя проверить HTTP-статус и `Location` новых редиректов.
- После следующего обновления GSC сравнить количество `noindex` и дублей.
- Через 4–8 недель сравнить запросы ламината и отмостки с этим снимком.
- В следующем еженедельном снимке добавить разрез GSC по страницам и
  устройствам.
