# D1: читаемость и мобильная навигация — 2026-09-09

## Исправлено

- Добавлен отсутствовавший `accent-950` в основной, бронзовой и океанской палитрах. Существующий `dark:bg-accent-950/20` теперь получает CSS; карточка покупки больше не сохраняет светлый фон в тёмной теме.
- Усилен контраст пояснения покупки и пустого результата.
- Автопрокрутка использует тот же CSS scroll margin, что и кнопки перехода между параметрами и результатом: 144 px на узком экране, 96 px начиная с sm. Учитываются шапка и мобильная панель.
- Удалено «слева» из инструкции, поскольку на телефоне форма расположена выше.

Формулы, значения по умолчанию, упаковки, маршруты и SEO-контракты не менялись.

## Границы результата

Это локальная браузерная проверка на эмулируемых ширинах, не испытание физических устройств и не сертификация WCAG всего сайта. Измерены три текста карточки покупки, а не все тексты и кнопки. Полная приёмка главной, ошибок во всех темах, остальных типов карточек и production остаётся открытой; D1 целиком не объявляется закрытым. Локальная главная/production build требуют рабочей конфигурации Ghost, не подменяем её пустым блогом. Сборку проверять отдельно в CI, выкатку — на production.
