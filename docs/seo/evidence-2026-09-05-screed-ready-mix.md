## Карта интентов и решение

| Группа | Владелец | Подтверждённый пробел / решение |
|---|---|---|
| Готовая смесь, пескобетон, М300, мешки | Существующий калькулятор | По умолчанию ручной замес; добавить конкретный путь к готовой смеси, пример фасовки и границу справочной модели |
| Расход на м², масса на комнату | Тот же калькулятор, без отдельной тонкой страницы | Объяснить, почему округлять мешки на каждом м² и затем умножать неверно |
| Толщина над трубой / полная высота | Существующая статья + ссылка из раздела калькулятора о тёплом поле | Статья уже ведёт к расчёту; добавить контекстный обратный путь для пользователя, который ещё не определил толщину |
| Несущая способность, толщина от нагрузки | Не обещать решение текущим калькулятором | Инженерного подбора нет; новый посадочный URL не создаётся |
| Наливной пол, полусухая технология | Исследование следующей итерации | Наличие единичных запросов не основание для новой страницы или изменения модели |

**Гипотеза:** понятный выбор режима и фасовки помогает посетителю из поиска выполнить расчёт. Рост кликов, конверсии и позиции не доказан; запросы и периоды сохранены для наблюдения.
