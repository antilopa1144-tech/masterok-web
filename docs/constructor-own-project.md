# Первый проект по своим размерам

Основной вход с главной и кнопка «Создать свой проект» на `/konstruktor/` открывают настройку первого помещения. Тип, название, ширина, длина и высота задаются до появления проекта в редакторе. Вход с `/konstruktor/vannaya/` сразу открывает размеры с существующим примером ванной и его настройками плитки.

Запрос `?new=1` означает явное создание проекта. Сохранённые проекты и готовые примеры `?start=…` продолжают открываться напрямую. Если работа уже сохранена, главный экран предлагает её продолжить; на посадочной есть отдельная кнопка нового проекта. Действие «Новый проект» внутри списка редактора использует ту же форму. Отмена сохраняет прежнюю работу.

Форма `RoomCreationForm` переиспользуется. Новая работа не существует в истории, IndexedDB и аналитике открытия, пока пользователь не подтвердит её. Отмена первого запуска возвращает к посадочной без автосохранённой демонстрационной комнаты. После подтверждения создаётся ровно одно помещение с указанными размерами; название проекта берётся из названия помещения и меняется в редакторе. Проверяется весь проект через `validateProject`.

Формулы, упаковки, пределы ввода, пресеты существующих примеров и формат файла версии 5 сохранены. Мобильное приложение не затрагивается. Применённые при первом запуске размеры сравниваются с исходным примером: аналитика учитывает собственный результат, не передавая числа, названия и идентификаторы. Черновик не считается началом работы.

На индексируемых страницах конструктора и ванной уточнены основной сценарий, метаописания, FAQ и видимая инструкция по замерам. Блок доступен в серверном HTML. Новых страниц и дублирующих URL для индексации нет; редактор остаётся `noindex`. Видимый FAQ главной посадочной и имеющаяся разметка используют общий список вопросов.

Дополнительная FAQ-разметка ванной не вводилась: Google сообщил о прекращении FAQ rich results в мае 2026 года и удалил документацию в июне. Усиление контента не считается доказательством роста позиций или трафика. Источник: [Google Search documentation updates](https://developers.google.com/search/updates#june-2026).

## Проверки

Полный набор: 4066 тестов в 295 файлах. Lint, TypeScript и production-сборка прошли; остаётся прежнее предупреждение `BlogCoverImage` о `alt`.

Проверены обычный старт с главной и ванная с посадочной на 1440 и 390 px, светлая и тёмная темы, ввод пустого названия и ширины 299 мм, отмена и перезагрузка. Ванная 2450,5 × 3100 × 2650 мм и кухня 2400 × 3600 × 2750 мм открываются без дополнительной демонстрационной комнаты. Ведомость и скачанные файлы содержат одно выбранное помещение, точные размеры сохраняются после перезагрузки.

На 320 × 568 название из 120 символов не создаёт горизонтального переполнения, кнопки подтверждения и отмены остаются на экране. Исправлена лишняя внешняя прокрутка: пояснения для скринридера теперь находятся внутри прокручиваемого тела формы. Отмена первого запуска оставляет список проектов пустым. Импорт файла ванной сохраняет дробную ширину 2450,5 мм.

Из списка редактора создан отдельный проект с помещением без обстановки 300 × 300 × 6000 мм: площадь 0,09 м². Прежняя работа остаётся в списке и открывается с исходными размерами. Отмена создания возвращает к списку без новой записи.

Обе посадочные возвращают HTTP 200 и содержат инструкции по замерам в серверном HTML. Canonical указывает на соответствующую страницу, robots разрешает индексацию; редактор остаётся `noindex`. Восемь видимых вопросов основной посадочной соответствуют имеющейся JSON-LD-разметке.

Артефакты: `output/constructor/own-project-2026-10-11/`. Проверка физического телефона и экранной клавиатуры не проводилась. CI, deployment и публичный сценарий проверяются после push отдельно.
