# Выбор сохранённого проекта на входе в конструктор

Дата проверки: 7 октября 2026 года.

## Пользовательский результат

Кнопка «Мои проекты» на `/konstruktor/` и `/konstruktor/vannaya/` открывает список проектов этого браузера. Для выбора старой работы больше не нужно предварительно загружать последний проект в 3D-редакторе.

В списке видны название, число помещений, дата и время изменения, отметка последнего открытого проекта. Поиск работает по частям названия, без учёта регистра, порядка слов и различия е/ё. Одинаковые названия не объединяются: каждая строка ведёт к исходному ID проекта. Порядок списка сохраняется из хранилища — сначала последние изменения.

Список читается только при открытии окна и обновляется при повторном открытии. Для отсутствующих проектов, пустого поиска, загрузки и ошибки хранилища предусмотрены отдельные состояния; ошибку можно повторить. Закрытые окна игнорируют запоздалый ответ чтения.

Использован нативный dialog с изоляцией фонового интерфейса, блокировкой прокрутки страницы, обходом Tab / Shift+Tab и возвратом фокуса после Escape или закрытия. Поиск не получает фокус автоматически, чтобы при открытии на телефоне сразу видеть список.

FAQ обеих страниц дополнен инструкцией поиска сохранённой работы. Правила расчёта, структура IndexedDB и формат файлов не менялись. Открытие из списка не создаёт копию; импорт файла по-прежнему создаёт отдельный проект.

## Затронутые файлы

- `ConstructorSavedProjects.tsx` и `.module.css` — окно и состояния списка.
- `ConstructorStartActions.tsx`, `ConstructorImportAction.tsx`, `constructor-entry.module.css` — общая строка действий «Мои проекты» / «Открыть файл проекта».
- `src/lib/constructor/project-list.ts` — поиск без изменения записей и порядка.
- `ConstructorSavedProjects.test.ts`, `tests/engine/constructor-project-list.test.ts` — ошибки, повторное чтение, отложенный ответ, точные ссылки и поиск.
- `src/app/konstruktor/page.tsx`, `vannaya/page.tsx` — FAQ.

## Ограничения

Мобильные проверки выполнены при заданной ширине браузера, не на физическом телефоне. Пустое хранилище, ошибка чтения и поздний ответ проверены компонентными тестами; существующие пользовательские данные для этого не удалялись. Нативные механизмы dialog проверялись в браузере, а не по заглушкам jsdom.

Перед публичным релизом остаётся проверка экранной клавиатуры и переключения проектов на реальном телефоне. Результат тестов и push не подтверждает публикацию или поисковый трафик.
