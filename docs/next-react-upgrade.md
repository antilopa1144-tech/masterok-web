# Next.js 16.4 и React 19.3

Обновление выполняется отдельно от TypeScript, Three.js и Tailwind: Next.js 15.5.25 → 16.4.0, React/React DOM 18.3.1 → 19.3.0. Типы React и bundle analyzer согласованы с этими версиями. TypeScript остаётся 5.9.3.

## Обязательная миграция

- `next lint` заменён на ESLint CLI и flat config. Обязательные проверки Hooks и Core Web Vitals сохранены. Новые диагностики React Compiler показываются предупреждениями; сам Compiler не включён. Сейчас lint проходит с 89 предупреждениями, преимущественно о существующих паттернах эффектов и refs. Их исправление требует отдельного рефакторинга, а не изменения поведения ради обновления зависимостей.
- Dev/build явно используют webpack, включая локальный launcher commerce. Существующий webpack-конфиг, PostCSS, SSR и режим кэширования сохраняются; Turbopack и Cache Components не включаются.
- JSX использует автоматический runtime `react-jsx`. В root tsconfig сохранены посторонние include локального commerce; в коммит входит только обязательная смена JSX.
- Несколько `useRef` явно инициализируются `undefined` и допускают его в типе. Начальное значение, таймеры, камера и перемещение не меняются.
- Вебхук блога вызывает `revalidateTag(tag, { expire: 0 })`, сохраняя немедленное истечение кэша. Профиль `max` здесь изменил бы прежнее поведение. Проверка read-only ISR использует управляемое время: запись должна быть создана строго до инвалидации тега.

`middleware.ts` сохраняет Edge runtime и правила 301/308/404/CSP. Next 16 поддерживает этот вариант с предупреждением об устаревшем имени. Переименование в Node.js proxy — отдельная миграция runtime.

Формулы, запасы, упаковки, данные проектов и Flutter не меняются.

## Проверки

- 4112 тестов в 305 файлах; lint без ошибок, TypeScript и production-сборка.
- Вебхук, read-only ISR, middleware и CSP: 39 точечных проверок.
- Создание ванной, два варианта, применение/отмена/повтор, сохранение/перезагрузка, реальный импорт файла и неверный ввод на ширинах 1440/390/320 px.
- Четыре сценария 3D, все декоры, швы, камера, выбор мебели и перемещение на 10/1 мм; PNG; 3D кровли и лестницы; темы и мобильное меню.
- Публичные SEO-страницы и noindex редактора. Мобильные проверки выполняются в эмуляции браузера, не на физических устройствах.

Известная React #418 остаётся отдельным риском. Локальные сценарии и 12 замедленных перезагрузок с production analytics markup не воспроизвели её. Это не доказывает устранение причины; публикация проверяется отдельно.

Официальные основания: https://nextjs.org/docs/app/guides/upgrading/version-16 и https://nextjs.org/docs/app/api-reference/functions/revalidateTag.
