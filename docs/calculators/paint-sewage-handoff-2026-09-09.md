# Paint / sewage: проверка незавершённого пакета

Дата: 2026-09-09. Пакет продолжает ранее подготовленные изменения, а не новый аудит каталога.

## Поведение

Краска: грунтовка больше не добавляется для уже загрунтованной поверхности или обычной перекраски. Она появляется для явно выбранной новой необработанной поверхности. Уточнены подписи подготовки; нулевая площадь покрыта регрессией. Контракт и Flutter-адаптер согласованы.

Септик: вместо автоматически назначенных колец, щебня, геотекстиля и фитингов — суточный приток, минимальный рабочий объём и проверка явно введённой системы. Труба округляется по введённой длине товарного отрезка, остальные позиции берутся из проектной ведомости. Результат не является проектом размещения/очистки. Правила и ссылки на нормативную базу сохранены в canonical-спеке; 9 сентября карточка СП 32.13330.2018 на Росстандарте подтверждает действующий статус и изменения 1–5.

В этом проходе дополнительно исправлены SEO-описание септика, два дублирующихся ключа в totalsDisplay и зелёная отметка для ещё не введённой системы (теперь нейтральная карточка).

- Flutter: общий canonical parity + два адаптера + реальный экран септика — 82/82 passed; targeted analyze 5 файлов без замечаний.

- Дополнительно локальный результат септика осмотрен в браузере основным агентом.

Защита пустого блога не отключалась. Отдельный tsc --noEmit подбирает старую копию репозитория в output и существующие ошибки типов тестов; не объявляется зелёным.
