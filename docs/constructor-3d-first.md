# Простой вход в 3D вместо сложных раскладок

Дата: 2026-10-05. Этап после коммита `69e1810`, ветка `codex/constructor`. Проверен перед отправкой; публикация в production не выполнялась.

## Что изменилось для пользователя

Свежий переход на страницы раскладки плитки и ламината открывает короткое объяснение с изображением комнаты и кнопкой «Начать в 3D». Для обычной задачи больше не нужно сначала заполнять старую большую форму, а затем переносить параметры в конструктор.

- Плитка открывает отдельный пример «Плитка на полу»: одна комната, один пол, без автоматически добавленной облицовки стен. Для пола и стен есть отдельная ссылка на ванную.
- Ламинат открывает существующий пример пола с досками.
- На странице конструктора теперь четыре сценария; плитка также доступна из меню сайта.
- Прежние инструменты доступны вторичной ссылкой для ёлочки, диагонали, отдельных поверхностей и сохранённых схем. Они подгружаются отдельно.
- Ссылки с параметрами прежних инструментов автоматически открывают их исходный интерфейс. Сохраняются в том числе нулевой запас и незаполненные значения. Только рекламные параметры не включают прежний интерфейс.
- Обновлены пояснения, описания и FAQ двух страниц. Их адреса, поисковые заголовки и связанные калькуляторы сохранены.

Новый пример пола использует существующие значения редактора: комната 3000 × 4000 мм, плитка 600 × 600 мм, шов 2 мм, монтажный зазор 5 мм, запас 10%, 4 плитки в упаковке. Это начальный редактируемый пример. Формулы, упаковочные правила и canonical-спеки не изменены; Flutter не затрагивался.

Превью плитки получено штатным PNG-экспортом редактора. Иллюстрация ванной обновлена по фактическому примеру с плиткой и сантехникой.

## Ограничения и ручная проверка

Мобильные сценарии проверены в браузере с размером экрана смартфона. Физические iPhone/Android, экранная клавиатура и жесты несколькими пальцами в этом этапе не проверены. Существующее dev-предупреждение hydration nonce темы остаётся; в обычной рабочей папке есть посторонние незавершённые изменения оплаты, поэтому проверка типов и компиляция выполнялись изолированно.

Для ручной проверки: открыть `/instrumenty/raskladka-plitki/` → «Начать в 3D» → изменить размеры → выбрать материал → открыть ведомость → перезагрузить. Затем проверить `/instrumenty/raskladka-laminata/` и вторичную ссылку на прежний инструмент. Проверки публикации относятся к будущему конкретному деплою.
