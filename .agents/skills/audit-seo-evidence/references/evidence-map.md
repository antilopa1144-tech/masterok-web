# Карта SEO-доказательств

| Вопрос | Основной источник |
|---|---|
| Metadata и canonical | Next.js metadata и rendered HTML |
| JSON-LD | `src/components/seo/` и rendered script |
| Sitemap и robots | `src/app/sitemap.ts`, `src/app/robots.ts`, публичные endpoints |
| Внутренние ссылки | Rendered HTML и обход сайта |
| Индексация Google | Google Search Console |
| Индексация Яндекса | Яндекс Вебмастер |
| Трафик и конверсии | Яндекс Метрика и аналитика проекта |
| Доступность | HTTP-проверка из релевантного региона и логи |
| Сниппет и позиция | Актуальная выдача с оговоркой персонализации |

## Формат разбора

| Тезис | Статус | Evidence | Реальная правка | Проверка эффекта |
|---|---|---|---|---|

Статус выбирать из: `факт`, `требует live-проверки`, `гипотеза`, `неверно`.

## Минимальный source-check

Перед рекомендациями искать текущие реализации `metadata`, `canonical`, `CalculatorJsonLd`, `sitemap`, `robots`, `CalculatorSearch`, `metodologiya` и analytics. Пути и поведение могут меняться; не считать этот список доказательством без проверки текущего checkout.

## Приоритет правок

1. Ошибка индексации или canonical.
2. Несоответствие JSON-LD видимому контенту.
3. Недоступная или тонкая страница с реальным пользовательским пробелом.
4. Перелинковка и discoverability.
5. Эксперименты, измеряемые через live-данные.
