# Delegate Efficiently

## Сначала решить, нужен ли субагент

1. Если основной агент может безопасно закончить задачу одним непрерывным потоком, не делегировать.
2. Делегировать только независимые части без общей последовательной зависимости и конфликтующего владения файлами.
3. Сравнить пользу с дополнительным расходом: если выигрыш в качестве или времени неочевиден, работать одному.
4. Использовать максимум двух субагентов одновременно, не считая основного.

## Выдать узкое поручение

- Выбрать самый узкий подходящий project agent; для исследования и аудита предпочитать read-only профиль.
- Передать конкретный вопрос, точные пути, критерии готовности и короткий формат ответа.
- Передавать `fork_turns="none"` или минимально достаточное число последних сообщений, когда полный контекст не нужен.
- Просить доказательства и вывод, а не длинный журнал действий.
- Для реализации явно назначить непересекающееся владение файлами и предупредить, что другие агенты тоже меняют рабочее дерево.
- Запретить вложенное делегирование, если основной агент отдельно его не разрешил.

## Сдерживать расход

1. Ограничиться одной волной делегирования; вторую запускать только при новом независимом пробеле.
2. Для уточнения переиспользовать уже созданного агента, а не создавать нового.
3. Не запускать два одинаковых аудита и не просить каждого читать весь репозиторий.
4. Не делегировать одиночную команду, lint/test, маленькую правку, последовательный этап или работу в общих файлах.
5. Завершать или останавливать помощника, когда его результат больше не нужен.

## Сохранить качество

- Основной агент принимает архитектурные решения, интегрирует изменения, перечитывает итоговый diff и выполняет финальные проверки.
- Для высокорисковой формулы использовать не более одного независимого `calc-auditor` с высоким reasoning.
- Для UI или production отделять воспроизведение от реализации, если это действительно параллельные задачи.
- Не считать мнение субагента доказательством без проверки кода, теста, браузера или лога.

## Коротко отчитаться

Сообщить, что было делегировано, какой агент использован, что он подтвердил и какие решения основной агент проверил самостоятельно.
