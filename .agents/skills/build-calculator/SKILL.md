# Build Calculator

## Сначала определить контракт

1. Прочитать корневой `AGENTS.md` и проверить `git status --short`.
2. Найти существующие engine-спеки, definition, registry, тесты и parity-фикстуры только для нужного калькулятора.
3. Зафиксировать входы, внутренние единицы, формулу, полевые поправки, запас, упаковку и пользовательский результат.
4. Если меняется поведение, сначала описать старое и новое поведение. Для принесённого бага сначала добавить падающий regression-тест.

## Реализовать по слоям

1. Менять источник истины в `engine/`; не помещать формулы в React-компоненты.
2. Разделять нормализацию, чистую математику, строительные коэффициенты, запас, округление и упаковку.
3. Считать без промежуточного округления. Штучные покупки округлять вверх только на упаковочном этапе.
4. Возвращать точную потребность и итог к покупке отдельно; добавлять остаток, допущения, ключевые факторы и MIN/REC/MAX, когда они полезны.
5. Описывать поля, подсказки, meta и FAQ через `CalculatorDefinition` и существующие конфиги.
6. Обновлять registry и маршруты только через текущие паттерны. Не править `meta.generated.ts` вручную.
7. После изменений canonical-спеков выполнять `npm run sync:all`, затем внимательно отделять созданные генератором изменения от чужих изменений в dirty worktree.

## Проверить результат

1. Запустить точечные unit-тесты изменённого калькулятора.
2. При изменении формулы, полей, дефолтов, упаковок или результата запустить `npm run test:parity`.
3. Запустить `npm run lint` и обязательный перед коммитом `npm test`.
4. Для UI-изменений применить `$verify-user-flow`; для публикации применить `$ship-masterok`.
5. Не называть визуальную проверку завершённой, если подтверждены только исходники и тесты.

## Использовать карту

Прочитать [references/calculator-map.md](references/calculator-map.md) для полного цикла, выбора команд и критериев готовности.

## Отчитаться

Указать изменённый контракт, файлы, проверки, риски и ручные шаги. Для расчётной логики отдельно показать: старое поведение → новое поведение → эффект для пользователя.
