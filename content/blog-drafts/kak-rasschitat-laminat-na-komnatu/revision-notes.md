## Безопасность обновления

Операторский helper дополнен чтением опубликованного HTML (`--review-post`) и точечным `--revise`. Перед записью проверяются slug, публичный опубликованный статус, updated_at, SHA-256 и единственность каждого совпадения; media-блоки должны сохраниться. PUT изменяет только HTML и использует updated_at. Автоповторов нет, теги, авторы, статус, published_at и URL не передаются на изменение. Это отдельная операторская команда, не изменение runtime сайта.

Перед PUT сохранён серверный backup с правами 0600: `/tmp/masterok-underlay-article-g9C1TU/laminate-revision-2026-09-10.json.before.json`; отправлен `save_revision=true`. Backup не удалён, но `/tmp` не является долговременным архивом. Локальный снимок опубликованного HTML и предпросмотр находятся в игнорируемом `output/laminate-revision/`. Доступы и ключи в Git не попали.

Ghost при сохранении добавил HTML-card комментарии и переводы строк между тегами. После исключения только этих различий содержимое полностью совпало с проверенной редакцией, метаданные совпали с исходными. Это не повторное применение манифеста: повтор на изменённой версии отклоняется.
