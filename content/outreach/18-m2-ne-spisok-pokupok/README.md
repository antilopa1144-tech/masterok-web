## Как сняты иллюстрации

Источник: `https://getmasterok.ru/instrumenty/raskladka-laminata/`, production, 05.09.2026. Открыт обычный пользовательский путь «Параметры» → размеры 6000×3000 мм → доска 1285×192 мм → «Схема». Сохранены палуба 1/3, натуральный дуб, объёмный 2.5D-вид, меблировка. Затем изменено только направление длинной стороны доски.

Снимки элемента `[data-testid="laminate-room-preview"]`, viewport 1200×1000. Оба PNG: **1088×617**, вместе около 202 КБ. После визуальной проверки снимок с перекрытием фиксированным заголовком переснят обычной прокруткой; элементы страницы не скрывались, изображения не ретушировались. Кадры показывают геометрию и рисунок, не являются обещанием точности раскроя или экономии материала. Данные аккаунтов и внутренней аналитики на изображениях отсутствуют.

В кадры не включены числовые итоги закупки. В тексте нет переноса предварительного результата программы в универсальную норму. Учебная фасовка 2,2 м² **не привязана** к размеру доски в иллюстрации.

## Проверяемые утверждения

- 18 ÷ 2,2 требует минимум 9 целых упаковок только по площади; 8 × 2,2 = 17,6, 9 × 2,2 = 19,8.
- Для условных потребностей 19,80 и 19,81 м² округление даёт соответственно 9 и 10 коробок. Остаток последнего примера: 22 − 19,81 = 2,19 м². Это не рекомендации расхода для показанной комнаты.
- Источник общих монтажных оговорок: [официальная инструкция Quick-Step](https://int.quick-step.com/en/laminate/installation), проверена 05.09.2026. Чужие изображения не использованы. Конкретные требования производителя не объявлены российской обязательной нормой.
- Исходный модуль геометрии: `src/lib/tools/laminate-layout.ts`; UI: `src/app/instrumenty/raskladka-laminata/LaminateLayoutGenerator.tsx`. Формулы и дефолты не менялись, независимый полный аудит расчёта ламината этим пакетом не заявляется.

## Проверки

Запуск из корня репозитория:

```powershell
node content/outreach/18-m2-ne-spisok-pokupok/verify.mjs
node scripts/render-blog-draft-preview.mjs content/outreach/18-m2-ne-spisok-pokupok/article.md output/outreach-18-m2-preview.html
```

Три арифметических примера и два изображения прошли проверку. Локальный HTML просмотрен браузером на desktop 1200×1000 и mobile 390×844: обе иллюстрации загрузились, подписи не обрезаны, горизонтального переполнения страницы нет. Широкая таблица прокручивается внутри собственного блока; для площадки без поддержки таблиц используйте короткую версию или переложите строки в список, сохранив числа и оговорки.

При просмотре обнаружена жёстко заданная рубрика «Плитка» в старом preview-скрипте. Добавлен необязательный `preview_kicker`, HTML-экранирование сохранено; для прежней плиточной статьи проверен неизменный fallback. Это локальный renderer, не новая production-страница.

`npm run lint` — успешно. Полный `npm test`: 3242 passed, 2 failed — прежние несовпадения незакоммиченного `sewage.metaDescription` с шаблоном в `index.test.ts`. Эти файлы не относятся к редакционному пакету и не менялись. Сборка и тесты из чистого коммита проверяются CI после push.
